# Image Sequence to Animated WebP

A small Electron app that converts image sequences into optimized animated WebP files.

## Features

- Select a folder with sequential image files
- Set output resolution (width / height)
- Set frame rate
- Control compression quality and effort
- Toggle lossless mode
- Export optimized animated WebP

## Install and run

1. Clone the repository:
   ```bash
   git clone https://github.com/dipeshKhadka/webp-sequence-converter.git
   cd webp-sequence-converter
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm start
   ```

Or download the pre-built installer (`WebP Sequence Setup 0.0.1.exe`) from the Releases page and run it directly.

## Usage

- Click **Select Image Sequence Folder** and choose a folder with image files
- Click **Choose Output WebP File** to select the destination
- Adjust width, height, frame rate, quality, effort, and lossless options
- Click **Export Animated WebP** to create the file
